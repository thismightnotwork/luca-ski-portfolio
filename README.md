# Luca Finnis-Bernard — Alpine Skiing Portfolio

Personal skiing portfolio for **Luca Finnis-Bernard**: UK alpine ski racer, **BASI Ski UK Level 2** instructor, Hemel Ski Race Club (HSRC) racer, instructor at The Snow Centre Hemel and Knockhatch Adventure Park, and Snow Shepard Pro Team athlete.

## Gallery: add photos

1. Upload or commit any image to the `photos/` folder.
2. Supported types are `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, and `.avif`.
3. Push the change to `main`.

That is all: no manifest or HTML update is needed. The site reads the `photos/` directory through GitHub’s public Contents API and renders all supported images. A page that is already open checks for new photos every 60 seconds; newly opened pages show the latest committed photos.

Use clear filenames such as `tignes-slalom-2026.jpg` because filenames become the image alt text.

## Publish with GitHub Pages

In the repository, go to **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder. Your site will publish at:

`https://thismightnotwork.github.io/luca-ski-portfolio/`
